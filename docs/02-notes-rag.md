# Шаг 2. Поиск по заметкам и ответы с источниками

После проверки доступа к модели по подписке подключаем текстового бота на Node.js и TypeScript. Пользователь задаёт вопрос обычным языком, а бот отвечает по содержимому Markdown-заметок и указывает источник.

## Как это работает

1. Индексируем разрешённые Markdown-файлы из локального клона репозитория заметок. Делим текст по заголовкам и сохраняем путь и заголовок каждого фрагмента.
2. На запрос запускаем поиск по словам через SQLite FTS5 и поиск по смыслу через эмбеддинги. Объединяем результаты и передаём агенту наиболее подходящие фрагменты.
3. Агент при необходимости читает актуальный текст заметки и формулирует ответ по найденным материалам. В ответе указывает заметку и раздел. Если сведений недостаточно, говорит об этом.

Индекс обновляется при изменении файлов и удаляет фрагменты удалённых заметок. Способ получения эмбеддингов выбираем отдельно. Доступ к ответам модели по подписке сам по себе не подтверждает доступ к эмбеддингам.

## Как проверим

- Запрос с точным техническим термином и запрос своими словами приводят к нужной заметке.
- Ответ ссылается на реальный файл или раздел, в котором содержится использованная информация.
- После изменения заметки бот отвечает по новой версии. Если подходящей заметки нет, бот сообщает об этом.

На этом шаге бот работает с заметками в режиме чтения. Создание и правка заметок, а также голосовые сообщения идут следующими этапами.
